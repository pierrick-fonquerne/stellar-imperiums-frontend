# Stellar Imperiums — Frontend

Frontend du jeu de gestion de colonie spatiale **Stellar Imperiums**.

## Stack technique

- React 19
- TypeScript
- Vite
- Tailwind CSS 4

## Prérequis

- Node.js 22+
- npm ou pnpm

## Installation

```bash
npm install
npm run dev
```
